# tuic-client

TUIC 协议客户端实现，提供本地 SOCKS5 服务与 TCP/UDP 端口转发。

安装、启动与完整配置说明见使用文档：

- 客户端：<https://rust-proxy.github.io/tuic/client/>
- 快速开始：<https://rust-proxy.github.io/tuic/getting-started/>

协议规范见 <https://rust-proxy.github.io/wind/tuic/>。
